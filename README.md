# Sol's Radiance - Resource Pack

The resource pack for the **Sol's Radiance** Minecraft plugin (Java Edition **1.21.11**):

- the Sun-Forge Glaive and the Aurum Shackle, with vanilla-style textures and animation
- the screen-effect shader (supernova bloom, flash and corona)
- the sounds

## Playing on a server with the plugin

You don't need to do anything. The server offers this pack when you join; accept it.

## Installing it yourself

Download **[SolsRadiance_pack.zip](https://github.com/seeedey/SolsRadiance-Pack/releases/latest/download/SolsRadiance_pack.zip)**
and put it in your `.minecraft/resourcepacks` folder, then enable it under **Options → Resource Packs**.

The pack replaces the `rendertype_text` core shader. If another pack you use also replaces it, only the one
higher in the list will work.

## For server owners

The plugin offers this pack automatically. Its default `resource-pack.url` is:

```
https://github.com/seeedey/SolsRadiance-Pack/releases/latest/download/SolsRadiance_pack.zip
```

That link always points at the newest release. The plugin reads the pack's sha1 from the
`SolsRadiance_pack.zip.sha1` file published next to it. After a new release, run `/sol pack` to send the new
pack to players who are already online.

To use the pack without the plugin, set it in `server.properties`. Use `resource-pack` for the link
above, and `resource-pack-sha1` for the hash in the latest release's notes.

## How releases are made

Every push to `main` runs `.github/workflows/release.yml`, which zips the pack and publishes it as a new
release marked *latest*, with its sha1. The pack is generated by the plugin's build tools and pushed
here with `tools/publish_pack.py`. Edits made directly in this repo are overwritten by the next publish.
